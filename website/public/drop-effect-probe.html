dropEffect probe

How to use

  1. Open this page in two windows of the same browser () and put them side by side.
  2. Pick a scenario below, then drag a purple source onto a target. Every drag adds one row to the log.
  3. Do the scenarios in the checklist: inside one window, then from one window to the other, then with the copy modifier held until you release the mouse.
  4. Press Copy results in the window where you started the drags, and paste the text back.

Checklist

  1. Same window: source to Zone 1, 2, 3, 4
  2. Other window: source to Zone 1, 2, 3, 4
  3. Other window, copy modifier held: Zone 1 and Zone 2
  4. Other window: Zone 5, 6, 7 (native text fields)
  5. Start a drag, press Escape (set the scenario first)
  6. Drop on another app, with and without the copy modifier (set the scenario first)
  7. Drop outside any window (set the scenario first)
Copy modifier: Option (⌥) on macOS, Ctrl on Windows and Linux. Hold it until after you release the mouse.
